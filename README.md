# AI Workshop

Hands-on lessons for getting started with AI assistants, working with them on your computer, and building agents of your own.

## Start here

**[Set up GitHub with Claude on a Mac](lessons/github-on-mac/README.md).** Have Claude set up Git on your Mac and test it with a private practice repository. You’ll approve the sign-in yourself.

Give this to Claude in a local Code session, or paste it in chat if you need help finding Code:

> Read https://github.com/AnaSeahawk/ai-workshop and walk me through the GitHub-on-a-Mac lesson. Do the steps you can on my Mac. When you need me, give me one action at a time.

Future workshop topics include working with an AI assistant in a local coding environment and building a first agent.
