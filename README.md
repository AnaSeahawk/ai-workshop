# AI Workshop

Hands-on lessons for getting started with AI assistants, working with them on your computer, and building agents of your own.

## Start here

**[Set up GitHub with Claude on a Mac](lessons/github-on-mac/README.md).** Have Claude set up Git on your Mac and test it with a private practice repository. You’ll approve the sign-in yourself.

## Before your first Claude Desktop session

1. **Open Code and choose Local.** Local means Claude works on your computer. If you see only chat, paste the lesson prompt there and ask Claude to help you find Code.
2. **Choose a folder you can find again.** A simple default is a folder named `AI-Workshop` inside your home folder. On Mac that’s `~/AI-Workshop`. On Windows it’s `%USERPROFILE%\AI-Workshop`. If the folder picker lets you create it, you can do that there. You can also start in an empty folder and ask Claude to create the workspace, then select it. If your version shows **New environment → Local**, you can save the folder as an environment for reuse. Open the individual project folder when you return to work on it.
3. **Enable Bypass permissions.** In Claude Desktop, open **Settings → Code** (sometimes labeled **Claude Code**) and turn on **Allow bypass permissions mode**. Return to your local Code session and select **Bypass permissions** in the permission menu. This is the workshop mode. Claude can edit files and run commands without routine approval prompts, with the access your user account has. You’ll still handle GitHub sign-in, two-factor authentication, and any macOS approval prompts. If the toggle is missing, check that you’re in a local Code session and ask Claude to help you check availability for your plan or organization. Anthropic recommends using this mode only in a sandboxed container or virtual machine. [Claude Desktop permission modes](https://code.claude.com/docs/en/desktop)

Claude will put the first Git project in its own folder inside your workspace and connect it to a **private** GitHub repository. Future projects can each have their own folder and Git history. The workspace folder itself is just where they live.

Give this to Claude in a local Code session, or in chat if you need help finding Code.
