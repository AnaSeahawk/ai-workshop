# Set up GitHub with Claude on a Mac

Open Claude Desktop and choose **Code → Local** if available. Pick the model you want to work with. You can also start in regular chat and ask Claude to guide you to a local session.

Give Claude this instruction:

> Follow the public [GitHub-on-a-Mac lesson](https://github.com/AnaSeahawk/ai-workshop/tree/main/lessons/github-on-mac). Set up Git and GitHub on my Mac and verify that you can create, push to, and pull from a private practice repository in my personal account. Do as much as you can yourself. I’m new to Terminal. Whenever I need to do something, tell me exactly what to click or paste, what I should see, and when to say “done.” Give me one action at a time, then resume.

## For the assistant
